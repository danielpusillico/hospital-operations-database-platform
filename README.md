# Hospital Operations Database Platform

Diseño e implementación de una base de datos relacional empresarial en SQL Server para una organización de salud.

## Descripción

Este proyecto aborda problemas habituales de gestión de información en instituciones médicas, incluyendo integridad de datos, trazabilidad, consistencia entre áreas operativas y administración de información clínica y administrativa.

La solución fue diseñada siguiendo un enfoque iterativo, pasando por análisis de requerimientos, modelado conceptual, normalización, diseño lógico e implementación física.
